# Sub-Agents

[Sub-agents](https://docs.anthropic.com/en/docs/claude-code/sub-agents) for Claude Code — specialised assistants Claude can hand work off to, each with its own focus, model, and trigger phrases. Drop them into `~/.claude/agents/` and Claude pulls in the right one automatically, or you can call one by name.

To enable/disable these from the CLI, see the [`update-subagents`](../skills/update-subagents) skill.

## What's in here

```
agents/
├── ada-devils-advocate.md      business-analyst.md      code-reviewer.md
├── feature-finisher.md         ios-native-expert.md     nadia-security-auditor.md
└── ralphy.md                   seo-optimizer.md
```

## Install

```bash
# All agents (skips README.md)
mkdir -p ~/.claude/agents
cp agents/[a-z]*.md ~/.claude/agents/

# …or just one
cp agents/code-reviewer.md ~/.claude/agents/
```

Filenames don't matter — Claude Code discovers agents by the `name:` field in each file's frontmatter. Start a new conversation to pick up changes. Drop them into a project's `.claude/agents/` instead to share with everyone in that repo.

## How sub-agents work

- Each `.md` file has YAML frontmatter (`name`, `description`, `model`, optional `color`/`memory`) followed by the agent's system prompt.
- Claude reads the `description` to decide when to delegate — so the trigger phrases above matter. You can also invoke one explicitly by name.
- `model` picks the tier for that agent (`opus` for deep reasoning/review, `sonnet` for faster execution work).

See the [Claude Code sub-agents docs](https://docs.anthropic.com/en/docs/claude-code/sub-agents) for the full reference.
